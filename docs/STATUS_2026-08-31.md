## Large-video / HEVC architecture

The 275 MB HEVC Main10 regression exposed the old CPU conversion bottleneck and request-lifecycle coupling. The beta now uses:
- original private S3 upload retained intact;
- direct 0:00–3:00 FFmpeg stream copy instead of full H.264 transcode by default;
- DynamoDB durable jobs with two-day TTL;
- ECS worker polling every 5 seconds;
- conditional leases for restart recovery;
- visible phases: downloading, cutting, uploading to Gemini, preparing, coaching;
- retry/recovery without asking for a second video upload.

## Guided user flow

The active tab pulses in order and only the next action is highlighted: **Subir video → Seleccionar peleador → Características → Foco del coach → Analizar sparring**. Once submitted, the same area represents live analysis/report progress.
